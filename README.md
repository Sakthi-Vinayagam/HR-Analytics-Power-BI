# 📊 HR Analytics Power BI Dashboard

An interactive **HR Analytics Dashboard** built using **Microsoft Power BI** to analyze workforce, attrition, employee performance, engagement, and training insights.

## 📌 Project Overview

This project focuses on transforming employee data into meaningful HR insights through interactive dashboards and data visualization.

The dashboard consists of **two pages**:

* **Page 1 – Workforce Overview & Employee Insights**
* **Page 2 – Employee Performance & Engagement**

The project demonstrates practical skills in **Power BI, DAX, Power Query, data modeling, KPI development, and business-focused data visualization**.
